# Topology contract v1

The Cloudflare application is vendor-neutral. MQ, ACE, DataPower, and FTP collectors must normalize their evidence into the same graph document before import.

## Snapshot

A snapshot contains:

- `schema_version` — currently `1.0`.
- `snapshot_id` — optional; generated by the Worker when omitted.
- `created_at` — ISO-8601 timestamp; defaults to import time.
- `environment` — for example `production`.
- `discovery` — collector identity and discovery metadata.
- `nodes` — topology objects.
- `edges` — relationships between node IDs.

## Node

Required fields: `type`, `name`.

Recommended fields: `id`, `environment`, `scope`, `status`, `metadata`.

When `id` is omitted the Worker derives a stable ID from:

`type | environment | scope | name`

Collectors that emit edges should generate or preserve the same node IDs so edge references are resolvable.

Initial node types include `host`, `application`, `qmgr`, `queue`, `channel`, `listener`, `ace_flow`, `datapower_service`, `ftp_endpoint`, and `other`. New types can be added without changing storage.

## Edge

Required fields:

- `source`
- `relationship`
- `target`
- `relationship_source`

`relationship_source` must be one of:

- `observed` — runtime evidence directly showed the relationship.
- `configured` — the relationship exists in authoritative configuration.
- `inferred` — the relationship was derived and is not directly proven.

Optional fields are `id`, `confidence` (0–1), `evidence`, and `metadata`.

Every edge must reference two nodes contained in the same snapshot. Dangling edges reject the entire import.

## Activation safety

The import path follows this order:

1. Parse and validate the complete graph in Worker memory.
2. Store the validated normalized document in R2 as evidence.
3. Create an inactive `STAGING` D1 snapshot.
4. Insert nodes and edges under that inactive snapshot.
5. Verify persisted counts.
6. Atomically deactivate the previous snapshot and activate the new snapshot.

A failure before step 6 leaves the existing topology active.
